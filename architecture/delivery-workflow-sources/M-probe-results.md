## Other facts seen while probing
- `api.github.com` was blocked all session (check-invariants 29 `gh pr view`), while github.com git transport works. A CI-fix loop that calls `gh` or the REST API cannot run in an executor session; it needs the desk or an auto-mode session.
- `/bin/ps` blocked, `timeout`/`gtimeout` absent, `mapfile` absent, bash 3.2, `mktemp` needs a template under $TMPDIR (bare `mktemp` is denied).
- A datadog logging host was denied during `claude -p`; harmless for the probe but shows the sandbox allowlist is narrow.
